# Filament 5 feature parity

This page classifies every topic in the official [Filament 5 documentation index](https://filamentphp.com/docs/llms.txt). The 161-page URL set was audited on 2026-07-28 and revalidated on 2026-08-05. The deterministic parity validator checks the exact normalized URL-set digest, unique classification, rationale, repository evidence, and absence of deferred rows. The comparison is behavioral: Holo Panels uses Holo-JS, TypeScript, and framework-native renderers instead of Laravel, PHP, Livewire, and Blade.

The classifications mean:

- **Implemented**: the documented capability has a supported Holo Panels equivalent in the current public packages.
- **Intentionally different**: Holo Panels provides the relevant outcome through a deliberately different Holo-JS or framework-native mechanism.
- **Deferred**: the topic is in product scope, but its complete supported journey is not yet present. Internal-only primitives do not count as implemented.
- **Not applicable**: the topic is about Filament project governance, PHP/Laravel tooling, or a host mechanism with no Holo Panels product equivalent.

A classification applies to the whole linked topic. When only part of a topic exists, the row is **Deferred**. Evidence links point to the narrowest current source or behavior test; proposal documents are never implementation evidence.
